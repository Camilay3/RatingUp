# 0001 - Spring Boot como Backend

## Data
2026-09-25

## Status
Aceito

## Contexto
Necessitávamos de um framework robusto, seguro e produtivo para construir a API REST do sistema, capaz de lidar com injeção de dependência, segurança (Spring Security) e integração com banco de dados relacionais de forma fácil. (Contexto inferido a partir do código atual).

## Decisão
Adotamos o framework Spring Boot (Java 21) para o desenvolvimento da API backend.

## Consequências
Benefícios: Ecossistema vasto, produtividade com Spring Data JPA, fácil integração com JWT e facilidade de testes.
Desvantagens: Consumo de memória maior típico de aplicações JVM e curva de aprendizado para novos desenvolvedores.
