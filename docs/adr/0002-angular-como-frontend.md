# 0002 - Angular como Frontend

## Data
2026-09-25

## Status
Aceito

## Contexto
Precisávamos de um framework robusto e tipado para construir uma SPA (Single Page Application) complexa, que envolve consumo de APIs REST, rotas com guards e manipulação de estado, garantindo escalabilidade no código do cliente. (Contexto inferido a partir do código atual).

## Decisão
Adotamos o Angular com TypeScript como framework para o frontend.

## Consequências
Benefícios: Arquitetura opinativa e padronizada (injeção de dependências nativa, RxJS), tipagem estática que previne erros no client-side.
Desvantagens: Curva de aprendizado íngreme e verbosidade maior do que bibliotecas mais simples como React.
